# 7. Activity of Day 7

## Digital Fabrication III: CNC Router Milling & Cutting



On this day we printed out our pcb designs. To do a few settings of our pcb, we exported it to carbide motion website [Carbide3d](https://copper.carbide3d.com/) to set page settings, milling settings and many more. We uploaded the gerber file, drill file and outline file and all were adjusted to the size of the machine we had. After this we connected to carbide motion software that we used to control the pcb printing machine by setting the x,y,z axes. Once everything was set the job was started and we changed the milling tools mid way. The final product looked like this.
